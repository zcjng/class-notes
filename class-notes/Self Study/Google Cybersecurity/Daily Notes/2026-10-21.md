## 📝 Raw Notes

### Inside the OS
- Power on → **BIOS/UEFI** microchip loads the **bootloader** → bootloader starts the OS.
- App sends a request → OS interprets → directs to hardware → data flows back to OS → back to app.
- **Security:** the boot process is attack surface — the **BIOS is often not scanned by antivirus**. Tracing app ↔ OS ↔ hardware flow is how you investigate events.
- OS = resource manager: allocates/de-allocates memory, storage, CPU for competing processes. **Task manager** reveals misuse (e.g. malware hogging resources).

### Virtualization
- One physical machine → many isolated, software-defined environments.
- **VM** = software replica of a computer · **vCPU** = scheduled slice of processing time · **virtual storage** = abstracted volumes · **virtual hardware** = simulated NICs/RAM/chips.
- **Host OS** runs on bare metal; **Guest OS** runs inside a VM (Linux guest on a Windows host is fine).
- **Hypervisor** = the layer between hardware and VMs; it enforces memory boundaries so VMs can't read each other's RAM.

### Package managers
- **Package** = software + its files/dependencies. **Package manager** = installs/removes/manages packages and resolves dependencies.
- Debian family (Ubuntu, Kali, Parrot): `dpkg` / **APT**, `.deb` · Red Hat family (CentOS): **RPM** / **YUM**, `.rpm`.
- Security: always run the newest package version for bug fixes and patches.

### Linux file system & commands
- Root `/` → `/home` (users), `/bin` (binaries), `/etc` (config), `/tmp` (world-accessible — a common attack target), `/mnt` (external media).
- Absolute = from `/`; relative = from the current directory. `~` home · `.` here · `..` parent.
- `pwd` (where am I) · `whoami` (who am I) · `ls` (what's here) · `cd` (move) · `cat` (whole file) · `head`/`tail` (first/last 10 lines — `-n` to change) · `less` (page through, `q` to quit).

### Filtering
- `grep "pattern" file` → every matching line. Two arguments: pattern + file.
- `ls dir | grep users` → pipe output of `ls` into `grep`.
- `find /path -name "*log*"` (case-sensitive) vs `-iname` (case-insensitive); `-mtime -3` = last 3 days, `+1` = older than a day, `-mmin` for minutes.
