## 📝 Raw Notes

### Packet anatomy
- **Header** — routing metadata, often layered (Ethernet → IP → TCP/UDP). Fields: src/dst IP, ports, sequence numbers, length.
- **Payload** — the actual user data.
- **Footer/trailer** — end of the frame, Data Link layer only (Ethernet **Frame Check Sequence**). Most Layer 3+ protocols (IP) have no footer.

### IPv4 header — 13 fields
| Group | Fields |
| :--- | :--- |
| Sizing | **Version**, **IHL** (header length incl. options), **Total Length** |
| Addressing | **Source Address**, **Destination Address** |
| Delivery | **ToS/DiffServ** (priority/QoS), **TTL** (hop counter, dropped at 0), **Protocol** (ICMP/TCP/UDP) |
| Fragmentation | **Identification**, **Flags** (DF, MF), **Fragment Offset** |
| Integrity | **Header Checksum** |
| Optional | **Options** (e.g. security options) |

### IPv6 header — 8 fields
**Version**, **Traffic Class** (≈ ToS), **Flow Label** (packets of one flow), **Payload Length**, **Next Header** (e.g. TCP), **Hop Limit** (≈ TTL), **Source Address**, **Destination Address**.
Smaller and simpler than IPv4 — no checksum, no in-header fragmentation.

### Capturing traffic
- NIC by default only takes frames addressed to it + broadcast/multicast.
- **Promiscuous mode** → all wired frames on the segment. **Monitor mode** → wireless frames without joining an AP.
- Placement matters: right segment, **SPAN/port mirroring**, or a network tap.
- Decoding turns raw binary into structured, filterable fields.
- ⚠️ Capturing on shared networks gathers credentials — **unauthorised interception is illegal in most jurisdictions**.

### PCAP
- **Libpcap** — standard Unix capture library (used by tcpdump).
- **WinPcap** — old Windows port, deprecated.
- **Npcap** — modern Windows (Nmap project); loopback + raw 802.11.
- **PCAPng** — packets plus metadata, interface stats, decryption secrets, comments.

### Investigation uses
- Detect IoCs: unencrypted credentials, C2 traffic, beacons, port scans.
- Reconstruct the timeline of an attack chain.
- Filter millions of frames down to the conversations that matter.

### Wireshark
- Display filter operators: `==`/`eq`, `!=`/`ne`, `>`/`gt`, `<`/`lt`, `>=`/`ge`, `<=`/`le`.
- **contains** — exact text match inside a packet. **matches** — regex.
- Protocol filters are just the protocol name: `dns`, `http`, `ftp`, `ssh`, `arp`, `telnet`, `icmp`.
- **Follow stream** reassembles a conversation into readable request/response text — the fastest way to read a plaintext credential or HTTP download.
