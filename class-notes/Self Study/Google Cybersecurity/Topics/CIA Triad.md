# ⚖️ The CIA Triad

[[Google Cybersecurity|← Back to Course Hub]] · [[2026-10-14|2026-10-14]] · [[2026-10-15|2026-10-15]]

The **CIA triad** is a core security model that helps inform how organizations consider **risk** when setting up systems and security policies.

> [!INFO] The three pillars
> **Confidentiality · Integrity · Availability**

---

## 🔒 Confidentiality

The idea that **only authorized users** can access specific assets or data.

- Closely tied to the principle of **least privilege** (see [[OWASP Security Principles]]).
- *Example:* complex password requirements make it harder for a [[Threat Actors|threat actor]] to access data.

## ✅ Integrity

The idea that data is **verifiably correct, authentic, and reliable**.

- Uses **cryptography** — mathematical techniques to protect the security of information.
- **Encryption** can be used to prevent unauthorized access *and* ensure data (e.g. internal chat messages) **cannot be tampered with**.

## 📶 Availability

The idea that data is **accessible to those who are authorized to use it**.
