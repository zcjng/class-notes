## 📝 Raw Notes

### Databases
- A database is built for **scale, speed, and multi-user access** — spreadsheets are for single users and small data with manual tracking.
- Analyst queries: **login attempts**, **software/update status**, **machine → owner inventory**.
- Relational DB = multiple tables linked by shared columns. **Fields** = columns, **rows/records** = entries.
- **Primary key** = unique per row, no duplicates, no nulls, one per table. **Foreign key** = a primary key from another table; duplicates and nulls allowed, multiple per table.
- Example: `employee_id` in Employees (PK) ↔ `employee_id` in Machines (FK).

### SQL basics
- **Query** = a request for data from one table or a combination of tables.
- `SELECT` picks columns (`*` = all — avoid on large production DBs). `FROM` picks the table. End with `;`.
- `ORDER BY` sorts (default **ASC**; `DESC` reverses). Multi-column sort: `ORDER BY country, city` — second column breaks ties.

```sql
SELECT customerid, city, country
FROM customers
ORDER BY country, city;
```

### Filtering
- `WHERE title = 'IT Staff';` — exact match; strings in **single quotes**.
- `LIKE` + wildcards: `%` = any number of characters, `_` = exactly one character.
    - `'IT%'` → IT Staff, IT Manager · `'N_'` → NY, NV, NS (not NYPD).
- Numeric/date comparisons: `<`, `>`, `=`, `<=`, `>=`, `<>`/`!=`. Dates quoted as `'YYYY-MM-DD'`.
- `BETWEEN '2002-01-01' AND '2003-01-01'` — **inclusive** on both ends.
- `AND` = both must match · `OR` = either matches (must repeat the column each time) · `NOT` = everything except.
- `WHERE NOT country = 'USA'` ≡ `country <> 'USA'` ≡ `country != 'USA'`.

### Joins
- Joins link tables on a shared key. **Dot notation** (`employees.device_id`) is required when a column exists in both tables.
- `INNER JOIN` = only matches in both (intersection). `SELECT *` duplicates shared columns.
- `LEFT JOIN` = all left rows + matches · `RIGHT JOIN` = all right rows + matches · `FULL OUTER JOIN` = everything; gaps become `NULL`.
- `LEFT` and `RIGHT` produce identical results if you swap table order — use **LEFT JOIN** to find employees without an assigned machine.
