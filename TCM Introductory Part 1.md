
## Assessment 
External Network Pentest 
- Assessing an organization's security from the outside
- Methodology based on OSINT gathering
- 32 - 40 hours with another 8-16 for reports
Internal Network Pentest 
- Assessing an organization's security from  the inside
- Methodology based on Active Directory attacks
- 32 - 40 hours with another 8-16 for reports
Web Application Pentest 
- Assessing an organization's web application security 
- Methodology based on OWASP testing guidelines
- 32 - 40 hours with another 8-16 for reports
Wireless Pentest 
- Assessing an organization's wireless network security 
- Methodology based on the wireless type being used (guest WPA2-PSK WPA2 Enterprise)
- 4-8 hours per SSID 2-4 for reports
Physical Pentest / Social Engineering
- Assessing an organization's physical security and end user training
- Methodology depends on task and goals
- 16 - 40 hours with another 8-16 for reports

## Report 
- Reports should highlight executive and technical findings.
- Recommendations based on what was discovered.

## Debrief
- Walks through your report findings.
- Can be with technical and non-technical staff present
