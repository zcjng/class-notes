## 📝 Raw Notes

### Protocols & ports
- **HTTPS** = SSL/TLS encryption, port **443** (HTTP = 80) · **DNS** = names → IPs, port **53** · **TCP** = handshake-verified connections.
- **SFTP** over SSH = port **22**, uses **AES**. **Telnet** = port **23**, insecure alternative to SSH.
- **POP3**: 110 plaintext / 995 SSL-TLS (retrieves email from server) · **IMAP**: 143 / 993 (keeps mail on server, multi-device sync) · **SMTP**: 25 / 587 (routes email; port 25 abused by spam).
- **DHCP** server 67 / client 68; **ARP** is layer 2 with **no port** (ports are layer 7).

### Wi-Fi evolution
- **WEP** (1999) = broken/outdated · **WPA** (2003) = TKIP + MIC, vulnerable to **KRACK** · **WPA2** (2004) = AES + CCMP, still KRACK-able · **WPA3** (2018) = fixes KRACK, **SAE** handshake, 128-bit baseline (+192-bit Enterprise option).
- WPA2 **Personal** = shared passphrase · **Enterprise** = auth server, users never see keys.

### Firewalls
- Hardware (physical appliance) · Software (per machine or per server; cheaper but loads hosts) · **FaaS** (cloud-hosted, filters in the cloud before reaching on-prem).
- **Stateful** tracks connection state/behavior (higher protection) vs **stateless** static rules (blind to anomalies).
- **NGFW** = deep packet inspection + intrusion protection + live cloud threat intel.

### VPNs & proxies
- Normal traffic exposes public IP, data, location to the ISP. VPN = **encrypted tunnel**, masks IP/location.
- **Encapsulation**: encrypt packet → wrap in new outer packet addressed to the VPN server → routers route the outer packet → server strips it and forwards with the VPN's IP.
- **Remote Access VPN** = single endpoint ↔ server · **Site-to-site** = network ↔ network (complex).
- **WireGuard** = fast, lightweight, open-source · **IPSec** = mature, OS-native, enterprise-favorite but complex.
- **Forward proxy** = outbound traffic control (internal → internet) · **Reverse proxy** = inbound (internet → internal servers, hides real IPs) · **Email proxy** = anti-spam/phishing, blocks BEC/forged senders.

### Segmentation & zones
- Segmentation = smaller segments with own rules; contains **blast radius** (hotel guest vs staff Wi-Fi; faculty vs student subnets).
- **Uncontrolled zone** = public internet · **Controlled zone** = DMZ (public-facing) → internal network (private) → restricted zone (highest privilege).
- Firewall layers: **external** (internet→DMZ), **internal** (DMZ→internal), **restricted** (guards the crown jewels). Analyst example rule: only inbound **443** to DMZ web servers.
- **Subnetting** divides one network into subnets via IP + network mask; **CIDR** replaced classful A–E addressing; `/24` = 256 IPs (e.g. `198.51.100.0`–`198.51.100.255`).

### Network threats (start)
- **Interception attacks** = steal/alter data in transit (packet sniffing; on-path & replay variants).
- **Backdoor attacks** = bypass normal access via leftover or planted entry points; can host malware, steal data, or launch **DoS**.
- Impacts: **financial** (lost revenue, repairs, litigation/ransom), **reputation** (lost trust), **public safety** (power grids, water, military).
