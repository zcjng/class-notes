## 📝 Raw Notes

### Networks & infrastructure
- A network = collection of connected devices; located via **IP and MAC addresses**.
- **LAN** = home/office scale · **WAN** = city/country scale (the internet is a WAN).
- **Modem** = connects LAN to ISP; usually **one outgoing port** (one public IP). **Router** = connects networks, routes by IP, can include a firewall. **WAP** = emits Wi-Fi.
- **Switch** (wired) = forwards by MAC to the intended device only ("port multiplier"); **Hub** = outdated, repeats everything to every port → eavesdropping risk.
- Home ISP box = **3-in-1**: router brain + built-in switch (Ethernet ports) + WAP (antennas).
- Router modes: **Wireless Router** (default, network boss) · **AP** (Wi-Fi only, wired from main router) · **Repeater** (wireless rebroadcast, halves speed) · **Client/Bridge** (receives Wi-Fi for wired devices) · **WISP** (wireless to public hotspot + private firewall network).

### Cloud computing
- Remote servers/services over the internet; companies outsource network management to save money.
- **SaaS** = ready-to-use apps · **IaaS** = raw virtual servers/storage/containers · **PaaS** = pre-configured dev platform.
- **Hybrid** = on-prem + cloud · **Multi-cloud** = multiple providers · **SDN** = fully virtualized, programmable network.
- Benefits: **reliability, cost efficiency, scalability (elasticity)**.

### Data packets & performance
- Packet = header (IPs, protocol) + body + footer. **Bandwidth** (data/sec) and **speed** (packet reception rate) — irregularities can signal a network attack.

### TCP/IP & OSI
- **TCP** = connection + streaming; **IP** = routing/addressing; **ports** = software locations for prioritizing traffic.
- 4 TCP/IP layers: **Network Access** (packets, hardware) → **Internet** (IP attached; IP + ICMP) → **Transport** (TCP reliable/retransmits, UDP connectionless/real-time) → **Application** (HTTP, SMTP, SSH, FTP, DNS).
- **ICMP** = error info & status updates for dropped packets, connectivity, redirects.
- OSI 7 layers: Application (7) · Presentation (6, formatting/encryption/compression) · Session (5, sessions) · Transport (4, segmentation, TCP/UDP) · Network (3, IP, routers) · Data Link (2, MAC, switches) · Physical (1, binary, cables).
- **L2 stays local (MAC, switches) · L3 goes global (IP, routers)**.

### Addressing & ARP
- Public IP from ISP, shared for outside traffic · private IPs stay inside the LAN.
- **NAT** swaps private source IP for the public IP (TCP/IP layers 2 & 3).
- **DHCP** assigns IPs + DNS + default gateway (server port 67, client port 68).
- ARP: broadcast `FF:FF:FF:FF:FF:FF` → owner replies with MAC → saved in **ARP cache**. No authentication (1982) → **ARP spoofing** → MitM; **DAI** on enterprise switches drops fraudulent replies.
- IPv4 header (20–60 bytes): 13 fields incl. **TTL** (prevents infinite loops), checksum, fragmentation fields. Data section up to 65,535 bytes.
- **IPv4** = 32-bit, ~4.3B addresses · **IPv6** = 128-bit, 340 undecillion; streamlined header + Flow Label; prevents private address collisions.
