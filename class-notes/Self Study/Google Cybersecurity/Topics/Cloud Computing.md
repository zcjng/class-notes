# ☁️ Cloud Computing

## 📌 What it is

**Cloud computing** utilizes **remote servers, applications, and network services hosted on the internet**, rather than local physical devices. This model allows companies to save money and access more network resources by **outsourcing network management to third-party providers**.

### Cloud vs. Traditional Networks

- **Traditional networks** host web servers from a business's physical location.
- **Cloud networks** store resources and data in **remote data centers** accessible via the internet — companies don't house the servers physically; online services and web applications are accessible from anywhere.

> [!NOTE] The rise of cloud security
> As organizations migrate to cloud services, cloud security is increasingly relevant. CSPs offer on-demand storage, processing power, and analytics, leading to a focus on **identity-based security** in addition to traditional network-based solutions. → see [[Cloud Security]]

---

## 🧩 The Three Main Cloud Service Models

| Model | What it provides | Who manages what |
| :--- | :--- | :--- |
| **SaaS** (Software as a Service) | Ready-to-use software suites hosted and fully managed by the CSP; accessed remotely with no setup | Almost everything — just use the app |
| **IaaS** (Infrastructure as a Service) | On-demand raw **virtual computing components** — virtual servers, storage, containers | Company configures and manages the components themselves |
| **PaaS** (Platform as a Service) | Pre-configured cloud environments and tools tailored for **application developers** to build and deploy custom apps | Provider runs the platform; devs build on it |

---

## 🌍 Cloud Environments & Virtual Networking

- **Hybrid Cloud** — combining a company's own physical, on-premise hardware with third-party cloud provider services.
- **Multi-Cloud** — using services from **more than one distinct cloud provider** (e.g. AWS *and* Google Cloud).
- **Software-Defined Networks (SDNs)** — completely **virtualized** network infrastructure (virtual switches, routers, firewalls) hosted on the provider's physical data center servers and configured **programmatically**.

---

## 💡 Core Business Benefits

- **Reliability** — high availability, consistent uptime, and secure remote access with minimal connection interruptions.
- **Cost Efficiency** — eliminates massive upfront hardware expenses; companies outsource equipment maintenance, upgrades, and patching to the provider.
- **Scalability (Elasticity)** — instantly scale resources up or down via a dashboard to meet changing demands; only pay for what you use.
