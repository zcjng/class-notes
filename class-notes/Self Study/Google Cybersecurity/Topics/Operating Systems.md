## 📌 What is an Operating System?

- **Definition:** the interface that bridges the communication gap between **computer hardware** and the **user**.
- **Core purpose:** makes computers run as efficiently as possible while ensuring they are easy for humans to use.
- **Key concept:** translates human interactions into **binary** (0s and 1s — the computer's native language).

### Hardware vs. Software Evolution

- **Hardware** = the physical components of a computer.
- **The 1950s challenge** — early computers had no OS interface and could not run multiple programs simultaneously; users had to wait for a program to finish, reset the computer, and manually load the next one.
- **Modern OS capabilities** — run multiple applications at once and seamlessly manage external devices (printers, keyboards, mice).

### Common Operating Systems

- **Desktop/Laptop:** Windows, macOS, Linux.
- **Mobile:** Android, iOS.
- **Security industry:** **Linux** is highly popular and a primary tool for security professionals.

---

## 🛡️ The Role of OS Security

Operating system security protects and prevents threats such as **viruses, worms, and malware**, focusing on securing:

- Files
- Data access
- User authentication

### Security Analyst Responsibilities

A deep understanding of the OS is required to:

- Configure and maintain system security by **managing access**
- Manage and configure **firewalls**
- Set **security policies**
- Enable **virus protection**
- Perform **auditing, accounting, and logging** to detect unusual behavior

---

## ⚠️ Operating Systems and Vulnerabilities

Security issues are inevitable with all operating systems. An important part of protecting an OS is keeping it and **all of its components up to date**.

### Legacy Operating Systems

A **legacy operating system** is an operating system that is **outdated but still in use**.

- Some organizations continue using them because software they rely on is **not compatible** with newer operating systems — more common in industries using lots of equipment with **embedded software** (software placed inside components of the equipment).
- Legacy OSes can be vulnerable because they are **no longer supported or updated**, leaving them exposed to new threats.
