Primary purposes and functions of common security tools an entry-level security analyst uses. See also [[Logs & SIEM|logs & SIEM]] and [[Playbooks & Incident Response|playbooks]] for the deeper dives.

---

## 🛠️ Tool Overview

| Tool | What it does |
| :--- | :--- |
| **Antivirus software** (anti-malware) | Prevents, detects, and eliminates malware and viruses; can scan device memory for patterns indicating malware presence. |
| **Intrusion detection system (IDS)** | An application that monitors system activity and **alerts on possible intrusions**; scans and analyzes network packets to identify threats, theft, and unauthorized access. |
| **Encryption** | Converts data from a readable format (**plaintext**) into a cryptographically encoded format (**ciphertext**) to ensure confidentiality. |
| **Penetration testing** (pen testing) | A **simulated attack** that identifies vulnerabilities in systems, networks, websites, applications, and processes — a thorough risk assessment of external and internal threats and weaknesses. |
| **Network protocol analyzers** (packet sniffers) | Capture and analyze data traffic within a network — e.g. **tcpdump** and **Wireshark**. |

> [!NOTE] Encoding ≠ encryption
> **Encoding** uses a public conversion algorithm so systems with different data representations can share information. **Encryption** is specifically about making data unreadable to unauthorized users.

## 🌐 Web Vulnerabilities

A **web vulnerability** is a unique flaw in a web application that a threat actor could exploit using malicious code or behavior to allow unauthorized access, data theft, and malware deployment.

- To stay up-to-date on the most critical risks to web applications, review the **Open Web Application Security Project (OWASP) Top 10**.
