Physical Controls
- Limit physical access
- Guard shack
- Fences, locks

Preventive
- Limits access
	- Firewall Rules
	- Security policy
	- Guard shack
	-  Door locks
Deterrent
- Discouragement to not attack
	- Application splash screens
	- Threat of demotion
	- Front reception desk
	- warning signs
Detective
- Identify and warns, warning
	- Collecting and review system logs
	- Review login reports procedures like reviewing everyday
	- Regularly patrol the property
	- Motion detectors
Corrective
- Apply something after the event, maybe can reverse
	- Restoring from backups
	- Create policies for reporting security issues
	- Contacting the law enforcement 
	- Use a fire extenguisher
Compensating
- Event has occured but dont have the resources, so we use other means to control it
	- Firewall blocks instead of patching, maybe the patch isnt out yet  
	- implement a separation of duties
	- Having multiple security guards
	- Have a generator to compensate for electrical outage
Directive
- Directing subject towards security compliance, making them do more secure things
	- Store all sensitive files in a protected folder, ifle storage policies
	- Create compliance policies and procedures
	- Training on employees on the policies, performing a training course
	- Post a sign "Authorized personnel only"
