## 📝 Raw Notes

### Incident response lifecycle (M1)
- NIST IR lifecycle = **Preparation → Detection & Analysis → Containment, Eradication & Recovery → Post-Incident Activity**. It adds operational substeps to the strategic NIST CSF functions.
- **Event** = observable occurrence on a network/system/device. **Incident** = occurrence that actually or imminently jeopardizes CIA, or violates law/policy.
- **All incidents are events; not all events are incidents.**
- Investigation answers the **5 W's**: who, what, when, where, why. Recorded in the **incident handler's journal**.
- IR plans contain response procedures, system information (network diagrams, data flows, asset inventory), and supporting documents (contact lists, forms, templates).
- Documentation has no universal standard — orgs set their own. Forms: playbooks, incident handler's journals, policies, plans, final reports.

### CSIRT (M1)
- **CSIRT** (aka IHT or SIRT): specialized team trained in incident management. Goals — manage incidents efficiently, provide response/recovery, prevent recurrence.
- **Command** (leadership/direction) · **Control** (technical management, resources, tasks) · **Communication** (keep stakeholders informed).
- Roles: **security analyst** (monitor, triage, root-cause, escalate), **technical lead** (root cause + containment/eradication/recovery strategy, aligns with business priorities), **incident coordinator** (cross-department coordination).
- Non-security members: HR, PR, management, IT, legal.

### SOC (M1)
- **SOC** = unit dedicated to monitoring networks, systems, devices for threats. Blue-team work.
- Tiers: **L1** monitor/prioritise/ticket/escalate → **L2** deep investigation + tool tuning → **L3 (lead)** team ops + advanced detection (malware/forensics) → **SOC manager** hiring, metrics, reporting, exec communication.
- Specialists: **forensic investigators** (L2/L3, collect/preserve/analyse evidence), **threat hunters** (L3, hunt new/advanced threats with intel).

### IDS / IPS / EDR (M1)
- **IDS** monitors and alerts — it does not stop anything. **IPS** alerts *and* acts (e.g. edits an ACL to block traffic). **EDR** sits on endpoints, does behavioural analysis with ML/AI, and can auto-stop processes.
- Tools: Snort, Zeek, Kismet, Sagan, Suricata (many do both IDS and IPS). EDR: Open EDR, Bitdefender EDR, FortiEDR.
- Detection outcomes: **true positive** (correct alert), **true negative** (nothing there, no alert), **false positive** (alert, no threat — wastes time), **false negative** (threat, no alert — dangerous).

### SIEM & SOAR (M1)
- **Collect & aggregate** logs from firewalls/servers/routers/IDS → **parse** into fields → **normalize** into one standard format → **analyze** against rules → alert.
- **Correlation** = compare multiple events to find patterns.
- Example parse: `Apr 3 11:01:21 server sshd[1088]: Failed password for user nuhara from 218.124.14.105 port 5023` → host=server, process=sshd, source_user=nuhara, source_ip=218.124.14.105, source_port=5023.
- Tools: AlienVault OSSIM, Chronicle, Elastic, Exabeam, IBM QRadar, LogRhythm, Splunk.
- **SOAR** complements SIEM: automated workflows *respond* rather than just report, and centralize related incidents into single cases.

### Network traffic analysis (M2)
- **Network traffic** = amount of data moving; **network data** = the data transmitted between devices.
- **Baseline** = expected legitimate behaviour: src/dst IPs, transfer volume, timestamps/frequency, standard port/protocol pairs.
- Three vectors: **flow analysis** (volume, protocols, ports; **protocol-to-port alignment**; **C2 on unexpected ports** e.g. HTTPS tunnelled over 8088) · **packet payload** (data inspection, exfiltration detection) · **temporal patterns** (off-hours spikes, e.g. 2 AM transfer surge).
- **Exfiltration**: phishing entry → **lateral movement/pivoting** → package/compress data → exfiltrate (e.g. via compromised email). Detect via unusual outbound spikes; contain by blocking IPs at the firewall.
- **SOC** = security, IoCs, adversarial mindset. **NOC** = stability, latency, uptime, operational mindset.
