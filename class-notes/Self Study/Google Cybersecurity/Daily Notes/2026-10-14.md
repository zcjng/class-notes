### Security frameworks — core components (M3)
- **Identifying and documenting security goals** — clear objectives, e.g. aligning with regulations like GDPR.
- **Setting guidelines to achieve security goals** — new policies, e.g. how to handle data requests from users.
- **Implementing strong security processes** — procedures to ensure compliance, e.g. updating or deleting user profile information.
- **Monitoring and communicating results** — tracking internal networks, reporting potential security issues to relevant personnel.
- The **security lifecycle** is a constantly evolving set of policies and standards.

### Ethics — key reminders
- Counterattacking a threat actor is **illegal** (Computer Fraud and Abuse Act 1986, Cybersecurity Information Sharing Act 2015) — **you can only defend**. Hacktivists with political goals make it worse; only armies attack.
- ICJ conditions for a lawful counterattack: affects only the first attacker · is direct communication to stop · doesn't escalate · effects are reversible.
- Stay unbiased, transparent, evidence-driven; keep investing in and advancing your skills.

### Tools preview (deep dives live in later days)
- **Logs** = records of events (sign-ins, web service access); crucial for finding vulnerabilities and breaches. → [[Logs & SIEM]]
- **SIEM** = collects/analyzes log data in real time (Splunk Enterprise, Google Chronicle); provides dashboards, cuts data volume via alerts.
- **Playbooks** = manuals with detailed instructions for operational actions; **chain of custody** = documenting who/what/where/why of evidence; **order of volatility** = preserve volatile data first; investigate on **copies**. → [[Playbooks & Incident Response]]
- **Antivirus** prevents/detects/eliminates malware · **IDS** monitors activity and alerts on intrusions · **encryption** = plaintext → ciphertext (≠ encoding) · **pen testing** = simulated attack to find weaknesses.
- Linux = open-source CLI OS for examining logs · SQL = query large databases · Python = automate repetitive, precision tasks. → [[Linux, SQL & Python]]
