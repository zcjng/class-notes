# 👩‍💻 Security Analyst Roles & Skills

[[Google Cybersecurity|← Back to Course Hub]] · [[2026-10-14|Related day: 2026-10-14]]

## 🏷️ Common Job Titles

- Security analyst / specialist
- Cybersecurity analyst / specialist
- Security operations center (SOC) analyst
- Information security analyst

---

## 🎯 Core Responsibilities

- **Monitor and safeguard** an organization's information and systems.
- Act as **first responders** to detected threats within the internal network.
- **Proactive threat prevention** — take part in exercises like penetration testing / ethical hacking to find system weaknesses.
- Collaborate with **IT teams** to implement preventative software for identifying risks and vulnerabilities.
- **Ensure data protection** — work with development teams on data-protection processes and systems.
- Conduct **periodic security audits** — review security records and activities to ensure the confidentiality of sensitive information.

---

## 🛠️ Technical Skills

| Skill | What it means |
| :--- | :--- |
| **Programming languages** | Basic understanding of languages like **Python** and **SQL** to automate tasks and identify error messages. |
| **SIEM tools** | **Security Information and Event Management** tools identify and analyze security threats, risks, and vulnerabilities. |
| **Computer forensics** | Identifying, analyzing, and preserving digital evidence within networks, computers, and electronic devices (like forensic science in criminal justice). |

---

## 🔐 Data Classification: PII vs. SPII

- **Personally Identifiable Information (PII)** — data that can identify an individual, such as name, address, and IP address.
- **Sensitive Personally Identifiable Information (SPII)** — a *stricter* category of PII including **social security numbers, medical, financial, and biometric data**, which can cause more significant damage if stolen.
