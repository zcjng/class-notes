## ⚙️ Value of Automation

- Automation **reduces human error** and significantly **saves time** compared to manual processes.

---

## 🐧 Linux

- **Definition:** an open-source operating system that primarily uses a **command-line interface**, unlike macOS or Windows.
- **Security application:** security analysts often use Linux to **examine logs** and investigate system activities, such as reviewing error logs during unusual network traffic.

---

## 🗃️ SQL (Structured Query Language)

- **Function:** used to **create, interact with, and retrieve** specific information from large databases.

## 🐍 Python

- **Function:** a versatile programming language that security professionals use to **automate repetitive and time-consuming tasks** requiring precision.
