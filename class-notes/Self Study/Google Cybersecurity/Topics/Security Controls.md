# 🛠️ Security Controls

[[Google Cybersecurity|← Back to Course Hub]] · [[2026-10-14|2026-10-14]] · [[2026-10-15|2026-10-15]]

**Security controls** are safeguards designed to reduce specific security risks. They are used together with [[Security Frameworks|frameworks]] to establish a strong security posture.

---

## 🔑 Key Control Types

- **Encryption** — converts data from a readable format (**plaintext**) to an encoded, unreadable format (**ciphertext**) to ensure **confidentiality**.
- **Authentication** — verifies the identity of a user or system; ranges from basic username/password logins to advanced **multi-factor authentication (MFA)** using biometrics.
- **Authorization** — grants access to specific resources within a system, ensuring only authorized individuals can access particular data.

> [!INFO] CIA connection
> These controls are fundamental elements of the [[CIA Triad|CIA triad]] — a core security model that security teams use to protect organizations.

---

## 🗂️ The Three Categories of Controls

| Category | Nature | Examples |
| :--- | :--- | :--- |
| **Physical** | Measures that prevent physical access | Gates, fences, locks · security guards · CCTV / surveillance cameras / motion detectors · access cards or badges |
| **Technical** | Hardware / software solutions | Firewalls · MFA · antivirus software |
| **Administrative** | Human-related policies & procedures | Separation of duties · authorization · asset classification |

> [!TIP] For audits
> The three categories above (administrative/managerial, technical, physical) are the ones you **review during a [[Security Audits|security audit]]**.
